Author skill effects for data/<ns>/skill_effects/ — same step types as gear buffs; switch to Gear effect for gear_effects/: save buffs as *_effect.json and set rows as *_set.json (loader still accepts optional merged gear_effect + gear_effect_sets in one file).

Mode:

Effect identity

Builds skill_effects/*.json. The id should match the datapack path (slashes like folders).

Gear set bindings same folder: gear_effects/

Each row becomes one *_set.json file (same folder). while_equipped → passive_gear_effect or damage_taken_multiplier; procs → apply_gear_effect. Buff body lives only in the *_effect.json file (Display / Core / Steps below).

Effect levels

Level 1 is the JSON root. Each higher level is saved under levels as a full copy of that rank’s fields (merged over the root in-game) so you can bump numbers, steps, duration, etc. display lives on the root only — higher levels omit it in JSON. Optional skill_action per level is documentation only.

Passive / mastery skill_action

Writes data/<ns>/skill_actions/*.json with execution.type: "passive". Match skill_id to skill_nodes.skill_action_id. Trigger effects use form rows below (same fields as JSON). increase_effect_chance adds to the listed skill_effects roll (base chance + boost, clamped 0–1).

Passive features

Stat modifiers (per rank)

Lost Essence gear_type gate (optional)

Mastery execution

trigger_effects

One row per entry. chance is 0–1 per roll. Omitted keys use sensible defaults.

increase_effect_chance (additive)

Each row: skill_effects id → extra chance added to that effect’s trigger rolls (e.g. base 0.1 + 0.1 → 0.2).

Mob affix

Save under data/<ns>/mob_affixes/<id>.json. Rolled on scaled mobs (server config). Optional mob_skill uses the same shape as entity rules — only applies if the mob has no mob_skill from entity / mob-type / mod-namespace tuning.

skill_id must reference a skill_actions entry with execution.type: spell. chance_of_casting: 0–1 or >1 as percent (e.g. 12 → 12%).

Gear affix

Save under data/<ns>/gear_prefix/*.json or gear_suffix/*.json to match Affix slot. Stats use short ids (e.g. physical_defense); the game resolves them to lost_essence:<stat>. Optional level_bands per stat line pick min/max by item level.

gear_slots

stats

Skill — flow

One skill_actions/*.json per file with execution.type: \"flow\". Root fields requires_gear_types, skill_attribute, and optional requires_active_skill_effect are edited here (server blocks the cast if that skill effect is not active). Build nodes below and wire emit.next, emit.on_stop (movement), and on_hit chains on melee / spell nodes. Importing a legacy skill_action (non-flow) or JSON with lost_essence_skill_stages_v1 performs a best-effort conversion into this flow graph for editing — verify edges and params before shipping.

Lost Essence gear_type ids (lowercase). Casting requires a match in either hand unless the execution type ignores gear (passive-style).

Flow nodes

Food category

Writes data/<ns>/food_category/<id>.json — template referenced by food_buff via "food_category". Optional experience_gain_percent adds to RPG kill XP (multiple stacks add; e.g. 10 → +10% per stack).

Pool rows use add_max_* / experience_gain_percent. You can also use only stat modifiers below (e.g. strength only). Modifiers are flat ADD_VALUE for the buff duration. Use pool rows for eat-heal on HP/stamina/mana; stat_modifiers on max_health does not trigger that heal.

stat_modifiers

Shown on the Lost Essence buff HUD (not a vanilla mob effect).

Potion effects

Writes data/<ns>/potion_effects/<id>.json — ties Lost Essence stat bonuses to a vanilla mob effect’s real duration (milk / refresh / infinite beacon, etc.).

stats

Each stat is a flat ADD_VALUE applied only while the mob effect is active.

Output

Import accepts: skill/gear effect JSON; passive skill_action (skill_id + execution.type: passive); active skill_action for Skill (flow) mode (skill_id + execution — execution.type: \"flow\" or legacy shapes / optional lost_essence_skill_stages_v1, converted best-effort to the flow editor). mob_affix (id + multipliers / mob_skill); gear_prefix / gear_suffix affix JSON (stats / gear_effect_set); a single gear binding (*_set.json); a root array of bindings; optional merged gear pack; multi-section preview: paste one JSON block at a time.
