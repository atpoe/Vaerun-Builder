Lost Essence — main builder

Unified skill_actions, skill_effects / gear_effects, passive / mastery, gear affixes (gear_prefix / gear_suffix), and mob_affixes authoring (replaces separate skill-action-editor + skill-action-builder flows). Jump with the nav, use templates and + Add effect rows, merge fields, then preview JSON. Gear affix mode matches GearAffixRegistry JSON (stats, optional level_bands per item level). Mob affix mode writes data/<ns>/mob_affixes/*.json — optional mob_skill for periodic spell casts (same shape as entity mob_skill). Mobs and summons can also get skills from entity rules / summon stats; stored magic attack scales with magic_attack_multi on entity tuning JSON.

Skill action builder

Build a datapack skill JSON for data/<namespace>/skill_actions/ — buff self-effects (optional swing + particles), melee, or Geo spells. Geo damage uses damage_stat (Physical attack or Magic attack). Mobs, summons, and mob affixes can reference spell skills for AI casts (see Mob affix JSON mode). Use Skill passive/mastery JSON in Builder mode for execution.type: passive passives. The exported skill_id here must match skill_action_id on the corresponding skill_nodes/*.json row (same string).

Suggested order

  1. Simple mode + identity (or import an existing file)
  2. Costs & cooldown
  3. Skill type → read the focus card → optional cast wind-up (all types)
  4. Template → tune universal / melee (incl. extras) / effects / spell
  5. Optional trigger effects & gear, then preview & download

Simple mode

Skill identity

Written as skill_id in downloaded skill_actions JSON. The matching tree node uses skill_action_id with the same string (legacy datapacks may still use skill_id on the node).

Import

Load an existing skill_actions/*.json from your datapack or repo. Supported: buff (linear steps, or graph on import only), melee, and spell. passive files switch you to the passive/mastery builder. Older legacy types still import and are auto-mapped.

Costs & cooldown

Set stamina cost and/or mana cost (both non-zero is allowed). A cast spends both when both are set; the game checks mana first, then stamina, for failure messages.

Skill type

Quick start
  1. Follow the Suggested order above (costs → pick skill type below → cast wind-up if needed → tune the focused panel).
  2. Pick Skill type below, then tick what the skill does (ground: damage vs support).
  3. Use a template + Apply selected template for a working starting point.
  4. Scroll to Effects / Melee / Spell and tune numbers, then Preview skill JSON.

Ground spells place a SpellVisualEntity (your Geo “block” / VFX) and pulse damage, healing, or ally buffs in the hit volume — see Ground zone effect in the spell panel.

What should this skill do?

Pick a skill type above to see the right options.

This path builds self effects only (HoT, stat buffs, sounds, etc.). Use the Effects list further down — add steps with + Add effect.

Melee always damages enemies in a cone. Tune reach, hits, and damage below.

Want a buff on the same button? Use Trigger effects (skill_effects) or make a separate buff skill — this builder outputs one execution type per file.

A ground spell spawns an entity (your Geo) on the terrain. The game can either hurt enemies in that volume or help players in it — not both in one skill.

After you tick one, scroll to Ground zone effect for heal %, flat heal, or ally buff JSON. Use Hit area for circle vs row vs prism.

Projectiles fly out and damage what they hit. There is no standing heal circle on the ground (that’s Ground spell).

Tune speed, Geo trail, and on-hit damage below.

Universal lets you chain stages in order (melee -> projectile -> summon -> utility) and compiles to standard runtime execution JSON.

Use this when you want more advanced skill action building.

Cast wind-up (all skill types)

Delays the real skill (buff steps, melee cone, spell spawn, universal compile) until the wind-up ends. Pair with Cast look on buffs / spells, a Cast presentation universal stage, or spell cast sound / Player Animator. Set cast_repeat_interval_seconds to replay Player Animator + cast sound during a long channel. cast_lock_movement (default on) keeps you rooted server-side.

Universal stage chain

Create ordered stages. Use Remove stage on a card or Clear all stages to reset. Compiler uses last-write wins when two stages target the same runtime key; warnings appear below. Summon stages include y_offset on the card; summon_stats and optional nested summon mob_skill appear in the section below (open by default — collapse the summary if you want it out of the way).

Conflict inspector

Templates set skill type, costs, and the right execution shape. Tweak numbers and ids afterward.

Mine and Slash spell JSON → Lost Essence converter

Load a spell file from Mine and Slash (or the same JSON shape: identifier, config, attached.on_cast). You get a feature map, a short summary, and a best-effort LE draft you can load into the builder. Conversion is approximate — tune damage, Geo, and tags afterward. Sky meteors / rain: use projectile_vertical_drop (true vertical fall at target column) or ground bursts; the converter sets vertical drop when tags suggest it.

Effects run top to bottom

    
Each row is one effect. The game runs them in order when the skill fires. Preview / download uses execution.steps (a plain JSON array) — not execution.graph.nodes, which is only used internally when importing old files. Damage steps hit your RPG health pool (cost / risk). Hitting enemies uses melee or Geo spells, not this list. For HoT pulses, use Heal — over time: you can mix flat_each, percent_max_each (fraction of max HP), and stat + ratio_each in the same step.


    

      
Cast look — swing, particles, sound (optional, no Geo)

      
Same fields as ground_rupture / defender skills: the mod runs these before your effect list — no extra spell execution key required. Leave sound empty and animation at "None" to skip. Player Animator uses execution.player_animation (clip id from assets/<ns>/player_animation/). Particles from other mods: choose Other mod / custom id… and enter the full registry id (e.g. lost_essence:arcane_spark) — works for simple particle types.

Passive / mastery skill_action

    
Writes data/<ns>/skill_actions/*.json with execution.type: "passive". Reflect uses passive_reflect_modifiers (multiple rows) or legacy flat keys. Stat modifiers as above; optional passive_mainhand_gear_types / passive_mainhand_weapon_types narrow when bonuses apply. Gear mastery puts mastery_unlocks_gear_type_prefixes (and optional class_mastery) on execution — tree nodes only set skill_action_id (legacy skill_id) + layout; they do not carry those keys.

Reflect / mitigation

      
Each row → passive_reflect_modifiers[]. Mitigation stacks multiplicatively per axis; reflect damage sums (base = pre-thorn hit). UI percents → JSON decimals (e.g. 3 → 0.03). Uses skill_physical / skill_magic.

      

      

    


    

      
Stat modifiers (per learned rank)

      
Each row: multiply_total / multiply_base / add_value, stat id, per_rank × min(rank, cap_rank). Example: multiply_total with 0.02 = +2% per rank to the final stat value.

Works with stat passives (and stacks with weapon types above if both are set).

      Timing note: duration_seconds is effect lifetime. HoT/DoT ticking is controlled by each row's
      pulse_count + interval_seconds. Example:
      pulse_count: 4 + interval_seconds: 2 = one pulse every 2s for ~8s
      (first pulse after the first interval; not at apply time).
      Each HoT pulse can combine flat HP, fraction of max RPG health (percent_max_each), and
      final stat × ratio (e.g. stat: lost_essence:magic_attack, ratio_each: 0.44 → 44% of magic attack per pulse).
      Use template HoT — magic attack 44% / 2s ×4 or buff step Heal — over time for the same idea.

Effect levels

      
Set up Rules and Effects above first, then use this section: level 1 is the root (merged into every level in-game). + Add level effect copies the currently selected level (including all effect rows) into level 2, 3, … so you only change what differs. Optional skill_action per level is for documentation.

      

        

          
          
        

        

          
          

        

        

          
          
        

      

      

        

          
          
        

      

    

  


  

    
Mob affix builder

    
Datapack path: data/<your_namespace>/mob_affixes/<id>.json. Affixes roll on scaled mobs (server config). Optional mob_skill attaches spell-cast AI; it applies when the mob has no mob_skill from entity / mob-type / mod-namespace rules (affix fills the gap). Use chance_of_casting as 0–1 or as a percent > 1 (e.g. 12 → 12%). Spell damage uses damage_stat physical_attack / magic_attack on the mob’s stored LE stats.
